# Project Brain v0.6 实现总结

## 已完成功能

### 1. 数据模型 (answer_models.py)
- `AnswerResult`: 统一回答结构，包含 answer、key_points、evidence、related_context、uncertainties、confidence_breakdown 等
- `KeyPoint`: 断言级 provenance，每个关键点带 source_ids、evidence_ids、support 级别
- `ConfidenceBreakdown`: 分项置信度计算（retrieval、source、evidence_coverage、freshness、conflict_penalty）
- `RelatedContext`: 相关但非核心的上下文
- `NextAction`: 建议后续动作

### 2. 意图路由 (intent_router.py)
- 12 种意图类型：project_goal、current_state、feature_summary、mechanism_explanation、decision_reason、failure_experience、evidence_trace、version_history、task_next_step、test_result、file_or_module_lookup、generic_search
- 关键词匹配规则，无匹配时 fallback 到 generic_search
- Source class 推导：user_confirmed、verified_evidence、active_decision、active_knowledge 等

### 3. AnswerBrain 主模块 (answer_brain.py)
- `answer()` 主入口：问题理解 → 意图分类 → 检索 → 相关性门控 → 证据聚合 → 答案生成
- 相关性门控：根据意图策略过滤候选，优先 verified/active 事实
- 污染检测：code_block、version_plan、test_summary、example_only 等标记
- 证据覆盖计算：以 key_point 为分母，非搜索结果数量
- 分层输出：answer/key_points/evidence/related_context/uncertainties

### 4. 兼容性
- `brain_ask_v2()`: v0.6 增强版 ask，返回 AnswerResult
- 旧 `brain_ask()` 保持不变
- `schema_version="0.6"` 标识新版本

### 5. 测试覆盖
- 10 个新测试全部通过
- 35 个现有测试全部通过（无回归）

## 关键设计决定

1. **检索和回答分离**: SearchProvider 负责找候选，AnswerBrain 负责判断哪些能进入回答
2. **默认回答事实，不默认回答历史**: 历史版本放入 related_context
3. **断言级 provenance**: 每个 key_point 带 source_ids 和 evidence_ids
4. **污染过滤**: version_plan、test_summary 默认不进 main answer
